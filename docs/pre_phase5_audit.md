### Preprocessing and modeling integration

Raw mode preserves feature order, values, dtypes and ownership. Standardized mode
fits only x01–x06 on training rows and applies unchanged statistics to test rows;
x07–x25, T and Y remain unchanged. Tests cover constants, determinism, oracle/extra
fields, NaN/Inf, invalid shapes, labels/encodings, fit ordering, invalid refits and
replication isolation. Real replications **0,1,7,42,99** pass both modes and hash
immutability checks. Low-level arrays cannot establish provenance; callers must
provide the right training subset. The convenience loader enforces official splits.

All six default estimators accept X/T/Y; official orchestrators preserve 25-column
order and fit only on training observations. Synthetic integration fits all six in
both preprocessing modes. A sentinel regression changes test Y and oracle truth and
verifies neither reaches fitting or changes predictions. Test X predictions and
mu1−mu0 targets are aligned on the same test population. No tuning loop against test
truth was found. Defaults were rerun unchanged, with raw features.

`estimate_ate(X_test)` averages predicted test CATE for IPW/AIPW, whereas
`estimate_ate()` returns training Hájek/AIPW respectively. These are distinct
estimators/targets; the benchmark evaluates the former. Naive predicts a constant
training association for every evaluation row. AIPW's training ATE interval is not
an interval for test-average predictions or individual effects.

All **600/600** fits in the 100-replication benchmark succeeded. Every stored aggregate
metric in `reports/benchmark_summary.json` matches the rerun within absolute 1e-12,
excluding runtime; formatted summaries match exactly. No historical output was
replaced. This reproduces the code/results, not the unrecorded history of model
selection. Replications are not independent patient cohorts.
